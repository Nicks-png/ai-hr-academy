📱 Como conectar o WhatsApp (QR Code)
1

Configure as variáveis de ambiente no arquivo .env na raiz do projeto:

EVOLUTION_API_URL=https://sua-evolution-url.com
EVOLUTION_API_KEY=sua-api-key-aqui
EVOLUTION_INSTANCE=nome-da-instancia
2

Reinicie o servidor e clique no status do WhatsApp no topo da página para escanear o QR Code.

3

Configure o webhook na Evolution API apontando para seu servidor. A URL deve ser:
https://seu-servidor.com/webhook/whatsapp

🌐 Teste local com ngrok
1

Instale o ngrok em ngrok.com e exponha a porta 3000:

ngrok http 3000
2

Copie a URL gerada (ex: https://abc123.ngrok.io) e configure na Evolution API como URL do webhook:

https://abc123.ngrok.io/webhook/whatsapp
3

Sem ngrok? Use a aba Respostas → Simulador para testar o fluxo completo localmente.
